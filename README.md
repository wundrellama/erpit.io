# erpit.io

The source of the website at [erpit.io](https://erpit.io), for ERPit by RiRo Enterprises, LLC.

The site is one static HTML file. It has no build step, no scripts, no web fonts, and no requests to other sites. GitHub Pages serves it from the `master` branch.

To change the site, edit `index.html` and push to `master`.
